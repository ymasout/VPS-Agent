关于本设计稿

M7 Web UI 2.0 概念稿 · 2026-08-24 · 页面数据为设计示例,非生产数据

  1. 表面层级 — 页面平面 #0d0d0d → 卡片 #1a1a19 → 悬浮层,配 hairline 边框与顶部 1px 提亮,构成深度而非描边。
  2. 状态语义 — 成功 / 信息 / 警告 / 危险 / 中性五档,一律「图标 + 文字 + 颜色」,永不单靠颜色;状态色不与系列色混用。
  3. 数据质感 — 时间戳、ID、版本、指标一律等宽字体;大数字用比例数字;表格列用 tabular-nums。
  4. 不伪造趋势 — 事件 / 操作趋势来自审计表(有据);资源只有心跳快照,用 meter 而非历史曲线。
  5. 诚实标签 — 会话面板明确标注「规则分析 · deterministic」,不包装成模型推理;待审批操作展示 maker-checker 链与过期时间。
  6. 图表规范 — 色值取自已验证的深色数据可视化参考色板;sparkline 2px 线 + 末端点(带表面环);无框线、无虚线网格。
  7. 边界不越 — 无 Web SSH / 终端入口,无密钥回显,无全局执行按钮;写操作只经由「生成处置计划 → 独立审批」闭环。
